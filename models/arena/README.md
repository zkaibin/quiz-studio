# Arena Clash VRM bases

## Runtime primary model (CDN)

- **Seed-san** by VirtualCast, Inc.  
  URL: `https://cdn.jsdelivr.net/gh/vrm-c/vrm-specification@master/samples/Seed-san/vrm/Seed-san.vrm`  
  License: [VRM Public License 1.0](https://vrm.dev/en/licenses/1.0/)  
  Used for **Model Use** only (loaded at runtime, not redistributed in this repo).  
  Materials are recolored per fighter; mech props are hidden.  
  Not an official Dragon Ball asset.

## Local fallback

- `anime-base.vrm` — VRM 1.0 sample from `@pixiv/three-vrm` examples  
  (`VRM1_Constraint_Twist_Sample.vrm`), MIT via pixiv/three-vrm.  
  Used when the CDN model cannot be fetched.

Fighter identities (Goku / Vegeta kits, etc.) are original procedural kits + recolors, not licensed character models.
